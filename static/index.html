Як користуватися

  • Перетягніть позначки зліва в клітинки таблиці.
  • Власні позначки (після +): правий клік по іконці в списку — прибрати її зі списку (у клітинках таблиці вже вставлені зображення не зникають).
  • Клацніть по клітинці, щоб змінити текст. Якщо рядок закінчується позначкою — клацніть поза нею, щоб додати текст після неї; якщо вже закінчується текстом — такий клік відкриває редагування останнього тексту. Правий клік по зображенню в клітинці — видалити його.
  • Пензель: клацніть по краю клітинки, щоб намалювати або прибрати кольорову лінію.
  • Додати / видалити учасника — змінює кількість колонок; Додати часову стадію — новий рядок.
  • Зберегти / Відкрити — експорт і імпорт таблиці у JSON.
  • Завантажити — зображення таблиці (PNG).
