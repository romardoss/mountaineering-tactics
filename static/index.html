Як користуватися

  • Перетягніть позначки зліва в клітинки таблиці.
  • Клацніть по клітинці, щоб змінити текст; правий клік по зображенню в клітинці — видалити його.
  • Пензель: клацніть по краю клітинки, щоб намалювати або прибрати кольорову лінію.
  • Додати / видалити учасника — змінює кількість колонок; Додати часову стадію — новий рядок.
  • Зберегти / Відкрити — експорт і імпорт таблиці у JSON.
  • Завантажити — зображення таблиці (PNG).
